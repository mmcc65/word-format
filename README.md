# word通用格式

用于 Word/WPS 文档的通用排版 skill，只管理格式，不绑定课程、报告类型或文案内容。

技能文件位于 [word-format/SKILL.md](word-format/SKILL.md)，调用标识为 `$word-format`，显示名称为“word通用格式”。

## 使用

将完整的 `word-format` 文件夹放入个人 Codex 的 `skills` 目录，保留其中的 `agents`、`references` 和 `assets`。

调用示例：

> 使用 word通用格式排版这份文档。

> 使用 word通用格式排版这份文档，现场照片采用组图式排布。

默认采用单图居中、图注在下方的形式。只有明确指定“组图式排布”时，才启用两列图片布局。

## 格式范围

- A4 页面、正文中西文字体、字号、缩进及行距。
- 标题样式、编号及段前段后间距；分点小标题独立成段，说明正文另起一段。
- 原生图表题注、交叉引用和可编辑公式。
- 无底纹三线表、自适应行高、跨页续表及重复表头。
- 封面与目录分页、正文页码及交付前检查。

具体参数以技能文件为准。用户当前要求及指定模板优先于默认格式；附带图像仅用于说明布局形式。
