# word通用格式

将以下规则作为用户的通用 Word/WPS 格式默认值。根据文档实际结构应用，特殊格式以当前明确要求和指定模板为准；未规定的细节以清晰、协调和同类格式一致为原则处理。

## 适用范围

- 仅处理文档格式，不绑定课程、报告类型、内容大纲或章节名称。
- 格式整理保留原文内容及章节安排；用户另行要求的内容修改按当前任务执行。
- 用户当前明确要求优先于本 skill 的默认格式。只要求局部排版时，仅处理指定范围。
- 可复用 skill 只保留格式规则及无个人信息的示意素材，不收录来源文档中的姓名、学号、联系方式、绝对路径、私人文件名或原始照片；公开前检查全部文本、素材和提交元数据。

## 页面与正文

| 项目 | 默认格式 |
| --- | --- |
| 纸张 | A4，纵向 |
| 页边距 | 上、下、左、右均为 2.54 cm |
| 中文正文 | 宋体，小四（12 磅） |
| 西文及数字 | Times New Roman，12 磅 |
| 正文对齐 | 两端对齐 |
| 正文首行缩进 | 2 个字符 |
| 正文行距 | 1.5 倍 |
| 正文段前、段后间距 | 均为 0 |
| 正文外观 | 黑色，不加粗，无底纹、无高亮 |

以上正文段落规则不自动套用于标题、图片段落、题注、表格单元格及独立公式等其他元素。

设置字体时分别指定中文字体与西文、数字字体。缩进使用段落属性，不使用连续空格模拟；正文行距使用 1.5 倍行距，不以固定磅值代替。无底纹及无高亮应使用真正的无填充设置，不以白色填充代替。

## 表格与文本背景

- 所有表格及单元格均无底纹，包括表头、正文数据行、续表、重复表头和用于组图排布的布局表格；不使用表头填色或隔行底色。
- 文本背景保持空白：文字和段落均无底纹、无高亮，包括正文、各类标题、题注及表内文字。
- 使用真正的无填充、无底纹和无高亮设置，不以白色填充模拟空白背景，使页面背景变化时不会残留白色底块。
- 检查表格样式、条件样式、段落样式和直接格式中的背景设置，避免仅清除单元格直接底纹后，表头或隔行底色仍由样式继承。

## 标题层级与编号

- 标题层级与编号层级分别判断。编号外观不能单独决定某段是否为标题，正文列表不因带编号而自动成为标题。
- 根据当前文档的实际结构、用户要求及指定模板确定是否使用文档标题，以及需要多少级章节标题；不固定为四类标题，不要求每篇文档用全所有层级。
- 对已有文档，依据原有章节关系设置标题样式，不为套用格式增删章节、拆分正文或改写标题。无法从上下文确定层级且会影响结构时，询问用户。
- 文档标题与章节标题分别处理；文档标题不自动计为一级章节标题。章节标题采用与实际层级对应的 Word/WPS 标题样式及大纲级别，以支持导航和自动目录。
- 标题是否编号以及编号形式，按当前文档要求确定，不把“一、”“（一）”“1.”“（1）”“①”固定绑定到标题级别。
- 同一文档内，同级标题格式保持一致。普通编号标题左对齐、无首行缩进，行距为 1.5 倍；文档标题、章标题等大标题的对齐、缩进和段落间距按具体版式调整。

### 标题段前与段后间距

- 实际用作标题的“一、”“二、”等中文数字编号标题，以及“（一）”“（二）”等括号中文数字编号标题，均设置段前 6 磅、段后 2 磅；这是段落间距，不是行距。
- 使用段落属性设置上述间距，不插入空段落模拟间隔。该规则不将同类编号的普通正文列表升级为标题，也不自动套用于文档标题、章标题等另有版式要求的大标题。
- 标题加粗仍按下文规则处理：“一、”等中文数字编号标题加粗，“（一）”等其他编号标题默认不加粗；承担文档标题、章标题作用的大标题按大标题规则处理。

### 标题字体与字号

- 普通编号标题沿用正文的字体和字号：中文为宋体、小四（12 磅），西文及数字为 Times New Roman、12 磅。加粗按下述规则另行设置。
- 文档标题、章标题等大标题的字体和字号根据具体文档、用户要求或指定模板调整，不固定为宋体小四；同类、同级大标题的格式保持一致。

### 标题加粗

- 文档标题、章标题等承担文档或主要章节名称作用的大标题加粗；按实际结构判断，不将所有小节标题都作为大标题加粗。
- 编号标题中，使用“一、”“二、”“三、”等形式的标题整段加粗，包括编号和标题文字。
- 其他编号标题，如“（一）”“1.”“（1）”“①”等，默认不加粗；若该段实际属于前述文档标题或章标题等大标题，则按大标题规则加粗。
- 此处的编号标题规则只适用于实际标题，不将正文中使用中文数字编号的普通列表自动加粗或升级为标题。

## 原生图表题注与联动

- 图注与表注（图题、表题）使用 Word/WPS 原生题注机制，保留可编辑文本与自动编号域；不以手敲编号、截图或普通文本模拟原生题注。
- 图注和表题使用中文：图标签为“图”，表标签为“表”，说明文字用中文；不默认附加英文题注或将标签写成英文。正文交叉引用同样使用中文图表名称，说明中必要的专业缩写按内容保留。
- 图、表分别使用各自的编号序列。可用 SEQ 域实现自动编号；采用全文连续编号还是按章编号，依具体文档确定。按章编号时，章号与真实章节编号关联，不将章号手写为固定文本。
- 正文对图表的引用使用原生交叉引用，通过书签及 REF 等域关联对应题注，不手写可能随增删图表而失效的引用编号。按引用用途选择引用编号、题注文字或页码。
- 同类题注使用统一的题注样式，避免逐条直接格式覆盖，使修改对应样式后，同类题注的外观可以统一调整；图注与表注需要不同格式时，使用可分别维护的题注样式。
- 增删、移动图表或修改题注后，更新相关编号和交叉引用域，并在保存后核对显示结果、编号顺序和引用目标。原生域可能需要在 Word/WPS 中执行“更新域”后才刷新，不能承诺所有显示值会即时自动更新。
- 区分联动类型：更新域刷新编号和引用；修改样式统一调整外观。修改一条题注的描述文字只影响关联该题注文字的引用，不应改写其他图表的描述。

### 图片与题注外观

- 默认采用单图居中式：图片独立占一行并居中，图注在对应图片下方居中；表题在表格上方居中。
- 图片保持原始比例，不超出版心，不拉伸变形，保证图片中的文字与标识清晰可读。
- 图注、表题的中文字体为宋体，西文及数字为 Times New Roman；均为小四（12 磅），不加粗，使用 1.2 倍行距，包括跨页续表标注；通过对应题注样式统一设置。

### 可选图片形式：组图式排布

- 仅在用户明确要求“组图式排布”时，对指定图片或指定范围启用；未指定时仍使用默认的单图居中式，不因图片较多自动切换。
- 每行两张图片，各自下配图注；有多余一张时，末行单图跨两列居中。可组织成“2＋1”“2×2”“2＋2＋1”等布局，按图片数量及页面空间选择。
- 默认各图片和图注保持独立、可编辑，每张图仍使用原生自动题注及交叉引用，不把整组图片和图注合成一张图片；只有用户明确指定分图版式时，才使用分图说明及一个总图号。
- 优先使用无边框布局表格稳定排列图片；也可使用原生图片与无边框、无填充文本框组成的组合对象。布局表格不属于数据表，不套用三线表、表题、续表或重复表头规则；文本框组合方式见细则。
- 采用该形式时读取[组图式排布细则与参考](references/side-by-side-figures.md)；仅借鉴图片布局，其他格式仍按本 skill 已确认的规则执行。

## 表格样式与行高

- 表格默认采用三线表：表顶线、表头下方横线和表底线；默认不设置竖线及其他内部横线。指定模板或用户当前要求优先。
- 表格及所有单元格背景均按“表格与文本背景”一节处理，表头和续表也保持无底纹。
- 表内文字默认中文宋体，西文及数字 Times New Roman，小四（12 磅），不加粗，包括表头；内容拥挤时可在保证清晰可读的前提下适当缩小字号。
- 表内文字垂直居中；短文字及数值水平居中，较长的说明文字左对齐。根据内容合理设置列宽，保持同类列的格式一致。
- 表内所有文字段落（包括表头与续页重复表头）使用多倍行距，倍数为 1.2；不以固定磅值或单倍行距代替。文字行距与表格行高分别设置，正文仍为 1.5 倍行距。
- 行高根据单元格内容、换行、内边距及整表的视觉协调程度灵活调整，不固定为 1 cm，也不强制所有行等高。优先使用自动行高；需要最低留白时可使用最小行高，不使用可能裁切内容的固定行高。
- 优先通过合理列宽、行高和单元格间距保持清晰、均衡的排版。保证文字、公式及上下标完整显示，不为压缩页数而裁字、挤压内容或制造明显不必要的空白。
- 跨页续表沿用同一三线表风格，重复表头及其下方横线；其他跨页要求见下节。

## 表格跨页与续表

- 表格允许跨页，不强制整张表放在一页。根据可用版心自然分页，保留数据的原有顺序与完整性。
- 首次出现时，表格上方使用正常表题；每一个续页均在续表上方居中显示“（续）表号 表名”，如“（续）表1-1 示例数据”。格式参照[跨页表格示意](assets/table-continuation.svg)。该示意用于确定续表标注和表头复用方式，其他表格外观另按已确认规则处理。
- 续表始终使用原表的表号和表名，不作为新表递增编号。续表标注通过原生交叉引用关联原表题注，保持编号与表名可更新；不手写固定表号，不使用会递增编号的新题注。
- 每一个续页在续表标注下方重复完整表头；多行表头按完整表头组处理。优先使用 Word/WPS 原生“重复标题行”设置，列宽、列顺序及表头格式与前页保持一致。
- 表格跨页与单行跨页分别控制：普通数据行尽量保持完整；内容过长确需跨页的行按具体情况处理，不以禁止整表跨页解决。
- 单独位于表格外的题注段落不能仅凭“重复标题行”设置自动在续页出现。实际生成文档时，须实现续页标注并逐页验证；如因排版工具限制需要拆分为续表块，应保持原表身份、原编号引用和完整表头，并在后续内容变动、重新分页后复核每处续表。
- 保存并更新域后，逐页检查续表标注、重复表头、编号引用和数据衔接，确认续表标注与该页表头、表体相邻，不出现缺行、重行或标注错页。

## 公式

- 使用 Word/WPS 原生可编辑公式；DOCX 可采用 OMML 数学对象。分式、上下标、根式等保留结构，不以截图、图片或显示的 LaTeX 源码代替公式。
- 独立公式主体居中，不设正文首行缩进；需要编号时，编号在同一行右对齐。使用原生制表位等可靠布局方式，避免用连续空格模拟位置。
- 是否编号及采用全文连续编号还是按章编号，依具体文档确定，不强制给每个公式添加编号。
- 公式编号采用原生自动编号域，正文引用使用原生交叉引用；按章编号时与实际章节编号关联，不手写固定编号。
- 增删或移动公式后更新编号及交叉引用域，并在保存后核对显示结果；检查居中与右对齐效果，以及分式、上下标和多行公式是否完整显示。

## 页眉、页脚与页码

- 默认不添加页眉；具体模板或当前任务有明确要求时优先遵循。
- 正文页码放在页面底端居中，使用原生 PAGE 域，不手写页码数字。
- 封面和目录的所有页面均不显示页码；目录跨多页时，每一页都适用，不能只隐藏第一页页码。
- 有封面、目录时，使用适当的分节和独立页脚或条件域控制前置部分与正文的页码显示；采用分节方案时，解除正文页脚与前节的关联，避免删除封面、目录页码时连带删除正文页码。分节与下节明确要求的分页符分别处理，不因额外设置分节而产生重复换页或空白页。
- 未另行要求时，正文页码默认从 1 开始，正文后续分节保持连续；封面、目录不占用正文页码序列。该起始值为可覆盖的默认处理，用户指定其他起始值或模板已有明确规则时以其为准。
- 本节不要求每份文档都添加封面或目录；仅对实际存在或用户要求生成的部分应用对应规则。
- 保存后检查封面与目录全部无页码、正文页码位置及起始值正确，后续页面连续，没有因分节出现意外空白页。

## 封面与目录分页

- 文档实际包含封面时，在封面结束处插入一个 Word/WPS 原生分页符，使后续目录或正文从新的一页开始。
- 文档实际包含目录时，在整个目录结束处插入一个原生分页符，使正文从新的一页开始。目录跨多页时，分页符放在完整目录末尾。
- 此处使用真正的分页符，不用连续空段落模拟换页，不仅设置“段前分页”或仅用分节符代替用户要求的分页符。
- 页码控制与分页效果一并核对，避免重复插入分页符、带换页的分节符等造成多余空白页。目录更新后，检查目录末尾的分页符仍位于目录之外，正文仍从新页开始。

## 自动目录与列表

- 需要目录时，使用基于真实标题样式及大纲级别的 Word/WPS 原生自动目录；不以手写条目、点线和页码模拟目录。目录层数按当前文档需要设置，不要求每份文档都添加目录。
- 标题编号和正文列表均使用原生自动编号；标题编号与相应标题样式关联，正文列表保持正文身份。编号形式依当前文档确定，不将所有列表都作为标题收进目录。
- 按条目实际所属的组设置列表连续与重新开始；增删条目后编号应可更新。避免因转换为自动编号重复保留原先手写的编号。

## 正文分页与相邻关系

- 除封面、目录及当前明确要求的分页外，正文默认连续排版，由 Word/WPS 自然分页，不强制每章另起一页。
- 标题与紧随的下文保持同页，避免标题孤立在页底；使用恰当的“与下段同页”等段落属性，不将大量普通段落连成不可分页的一整块。
- 图片与对应图注保持同页；表题与表头及其后首个数据行保持同页，不能为了相邻关系将整个长表锁定在一页。续表按前述规则处理。

## 操作与交付检查

1. 先读取用户指定的当前文档和相关模板，确认本次处理范围。遵循可用的 Documents 文档技能进行 DOCX 操作；本 skill 的用户格式规则优先于工具或其他技能的通用设计预设。
2. 将默认字体、字号及段落属性落实到相应样式；检查直接格式与样式继承，避免标题、题注、表头出现主题底纹或格式冲突。仅排版时保留原文、章节顺序和图表数据。
3. 在 Word/WPS 或支持相应原生域的环境中更新自动目录、标题及列表编号、题注、公式编号、交叉引用和页码。目录更新及重新分页后再次检查页码与相邻关系，必要时再更新受影响的域。仅写入待更新标记不等于已更新成功。
4. 渲染实际最终文档，逐页查看页面图像，检查标题间距、背景、表格文字及 1.2 倍行距、三线表、续表标注与重复表头、图片及图注、原生公式、目录和页码。修正问题后重新渲染受影响的最终文档并检查。
5. 保存后读回最终文件，检查题注、公式、目录与引用仍保留原生对象或域，以及正文与表格格式是否正确。对照原文确认排版没有丢失或重复内容。
6. 按用户指定路径交付；只报告实际完成的保存、域更新和视觉检查。若当前环境无法更新原生域、渲染或验证某项要求，明确说明尚未完成的检查，不宣称已经验证。
